# Mover Workflow

1. Receive the approved role-change event and effective date.
2. Compare current entitlements with the new role package.
3. Identify toxic combinations and separation-of-duties conflicts.
4. Route exceptional access for approval.
5. Remove access no longer required.
6. Add approved new access.
7. Recalculate licenses, groups, application roles, and device requirements.
8. Notify the manager and system owners.
9. Schedule post-change access certification.

Access should not simply accumulate as an employee changes roles.
