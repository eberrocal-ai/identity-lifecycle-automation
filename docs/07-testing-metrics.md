# Testing and Metrics

## Test Cases

- Complete and incomplete HR records
- Duplicate identity
- Future and immediate effective dates
- Returning worker
- Department and manager change
- Application unavailable
- Partial provisioning success
- High-risk termination
- Retry and idempotency behavior
- Unauthorized event submission

## Metrics

- Percentage provisioned before start time
- Median joiner and leaver completion time
- Failed steps by target application
- Orphaned-account count
- Access-review completion rate
- Exceptions past expiration
- Licenses reclaimed
- Manual touches per lifecycle event
