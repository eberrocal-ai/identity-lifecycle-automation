# Controls and Exceptions

- Require authenticated, authorized source events.
- Apply schema validation and duplicate prevention.
- Use least-privileged connectors.
- Protect secrets outside code.
- Require approval for privileged and exceptional access.
- Alert on failed termination steps immediately.
- Reconcile intended versus actual access.
- Give exceptions an owner, compensating controls, and expiration.
- Preserve tamper-resistant audit records.
- Provide a tested manual emergency procedure.
